# BWSC2027規則・大会ガイドのMPC関連確認

## 確認した版

- 公式 Event Regulations Release Version 1.0（2026年5月7日公開、72ページ）
- 公式 Team Manager's Guide Version 1.0（2026年5月7日公開、41ページ）

2025年資料とは別に保管しています。本メモはMPCの運行制約に関係する条項を抜き出したもので、規則全文の代替ではありません。後続のRegulation Bulletin、Team Notice、最終ルートノートを大会前に確認してください。

## MPCのハード制約に反映する事項

- 競技イベント期間は2027年8月22〜29日、DarwinからAdelaide。時刻はACST（UTC+09:30）。Day 1の公式セレモニーは07:30開始、先頭車のリリースは08:00。各日の走行開始は08:00、公式終了は17:00で、日没後の走行は禁止。
- 開通道路では60 km/h以上を維持できない場合や、次のControl Stopに閉鎖前に着けない場合、競技継続資格を失う条件に該当する。安全・交通法規・停止可否・Control Stop閉鎖時刻を、巡航速度最適化より優先する。
- Challengerの太陽光集熱面積上限は6 m²、蓄電容量上限は11 MJ。容量はメーカーが承認したセル仕様に基づき計算されるため、実車電池の試験容量と規制上限を別の値として扱う。
- Control Stopは原則30分。到着ドライバーはタイマー開始前に単独で充電構成へ変更できる。17:00にタイマーが止まり翌08:00に再開する場合があり、翌朝のパネル向きは前日の向きと一致しなくてもよい。これは発電モデルの姿勢モード切替点になる。
- Challengerの蓄電パックは毎晩19:15までに切り離して封印し、翌朝06:15より前に封印を解いてはならない。夜間のSOC・充電最適化はこの制約を含める。
- Cruise controlはブレーキ操作または車両OFFで自動解除し、解除後に自動復帰してはならない。自動運転機能も手動入力またはOFFで直ちに解除し、自動復帰してはならない。当面は速度推奨として設計し、車両へ自動指令する場合は適法性と安全設計を別途確認する。
- 2027年のControl Stop位置・運転時間はルート調査後の公式ノートに記載される予定。2025年ルートの距離アンカーは2025ログの再構成に限って使い、2027年の運行計画へ流用しない。

## 2025ログを使うときの扱い

2025年と2027年では主な巡航時間・Challengerの6 m²／11 MJ上限・60 km/h規定は共通していますが、2027年のControl Stop運用、夜間パック封印、正式なルートノートを優先してください。2025実走行ログから推定する車両モデルと、2027大会で守る規則制約を別レイヤーにします。
